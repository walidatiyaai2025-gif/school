# School PDF 1.1.5 — XO: إعلان بين الجولات (Interstitial)

## سلوك اللعبة

- **المعدل:** بعد كل **6 جولات مكتملة** (فوز أو تعادل)، وليس كل 6 نقلات أو محاولات فتح اللعبة.
- الإعلان يُطلب قرب الجولة الخامسة، وعند انتهاء الجولة السادسة يظهر فقط على انتقال **«العب من جديد»** إذا كان جاهزًا. نص الزر يُنبّه إلى احتمال الإعلان قبل الجولة التالية.
- بانر XO السفلي يُزال قبل عرض الإعلان الكامل لتجنب ظهور إعلانين في وقت واحد وتخفيف ضغط WebView على الذاكرة.
- إذا لا توجد شبكة أو موافقة UMP أو إعلان متاح، **لا تتعطل اللعبة ولا تنتظر إعلانًا**، ويُسمح باللعب مجانًا. يظل عدّاد الست جولات مؤهلًا حتى عرض إعلان فعلي.
- يُحفظ عداد الجولات المكتملة محليًا، ويُصفّر فقط بعد تأكيد SDK عرض الإعلان. حذف الملف الشخصي يمسح العداد.
- نفس السياسة تنطبق على اللعب مع صديق وضد الكمبيوتر.

## Dashboard — تفعيل إعلانات حقيقية

1. ادخل **Super Admin → Ads** بعد نشر تحديث Backend والمخطط Migration عن طريق **حزمة Update الموقعة** المعتمدة، لا ترفع Setup ZIP على موقع قائم.
2. راجع سياسة **Families** الخاصة بالجمهور المختلط وأكمل الموافقات الصادقة. لا يكفي وضع علامة صح دون تحقق فعلي.
3. أنشئ في **Google AdMob → Ad units** وحدة جديدة بنوع **Interstitial**، ولا تعِد استخدام Banner Unit ID.
4. أدخل **AdMob App ID** و **Banner Unit ID** الحاليين و **Interstitial Unit ID** الجديد لنفس Publisher والمنصة (Android أو iOS).
5. فعّل مزود AdMob، ثم **Enable XO full-screen interstitial**، وتأكد فعليًا من أن الإعلان مناسب للأطفال ويمكن إغلاقه خلال **5 ثوانٍ** إن كانت التجربة قد تعطل اللعب، وأن المحتوى G وغير مخصص.
6. تحقق من `/api/v1/config`: `ads.enabled=true` وداخل مزود Android `interstitial_enabled=true` و`interstitial_unit_id` مضبوط. الإيقاف الطارئ يُلغي العرض.
7. تأكد من ملف `app-ads.txt`، جاهزية حساب AdMob، تصنيفات Google Play وPrivacy & Messaging، وتوقيع وبناء إصدار Android الإنتاجي قبل نشره.

**مهم:** إضافة كود Interstitial إلى GitHub لا تعني تشغيل إعلانات مدفوعة على الجهاز الآن. يجب تفعيل وحدة AdMob الجديدة في لوحة الإنتاج بعد تحديث Backend، والتأكد من الامتثال قبل النشر.

## اختبار Windows / Flutter Emulator

```powershell
cd C:\Live\sclpdf
git fetch origin
git switch feat/1.1.5-office-open-landing
git pull --ff-only origin feat/1.1.5-office-open-landing
cd mobile
flutter pub get
flutter run --dart-define=SCHOOLPDF_TEST_GAME_INTERSTITIALS=true
```

- هذه العلامة للتجربة **Debug فقط**؛ تستخدم معرف Google التجريبي الرسمي: Android `ca-app-pub-3940256099942544/1033173712` و iOS `ca-app-pub-3940256099942544/4411468910`.
- أكمل ست جولات من XO ثم اضغط **العب من جديد** لمشاهدة إعلان اختبار، بشرط جاهزية SDK وموافقة UMP. لا توجد إيرادات من Test Ads.
- بدون العلامة، حتى في Debug، يتحقق التطبيق من موافقة السيرفر ووحدة الإعلان أولًا، ويستخدم معرف Google التجريبي تلقائيًا في بيئة Debug.
- اختبر أطفال/مراهق/بالغ/مجهول (مجهول يُعامل كطفل)، فشل الإنترنت وUMP، إيقاف Backend، إعادة فتح التطبيق قبل الجولة السادسة، والعودة من الإعلان دون فقد اللعبة.
- لا تضغط على الإعلانات الحقيقية عند الاختبار؛ لا تفترض نجاح إعلانات الإنتاج من نجاح اختبار Debug.
