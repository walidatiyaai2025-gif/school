# School PDF v1.1.5 — Office intake, games, admin, and Android startup hardening (2026-11-25)

- تطبيق Flutter Android 1.1.5+5: فتح ملفات PDF والصور وOffice عبر مسارين مع موافقة واضحة، مع تحديث واجهة البداية وتجربة الألعاب التعليمية والتقدم والمكافآت.
- تحسين إقلاع Android: فشل التنظيف الاختياري لسجلات الجهاز لا يمنع فتح تطبيق المسح والعمل دون إنترنت. هذا دفاع إضافي وليس إثباتًا لإصلاح مخالفة Play السابقة؛ يلزم اختبار تشغيل إصدار Release على أجهزة فعلية وتحليل Android vitals.
- تحديث لوحة Laravel: إعدادات إعلانات الأطفال وسياسة Families، والاعتمادات المنفصلة لإعلانات الألعاب، ودعم تحويل Office على الخادم عبر LibreOffice عند تفعيله بأمان.
- تحويل Office عبر الخادم معطل افتراضيًا ويحتاج LibreOffice واختبار HTTPS وخصوصية الملفات على الاستضافة قبل تشغيله. فتح المستندات محليًا لا يعتمد على تشغيل المحوّل.
- حزمة SchoolPDF-Setup-v1.1.5.zip للتثبيت النظيف، وحزمة SchoolPDF-Update-v1.1.5.zip موقعة Ed25519 للترقية المدعومة من 1.1.4 فقط، مع التحقق من SHA-256 وتطابق المفتاح العام.
- التحديث يحمي .env وبيانات قاعدة البيانات والملفات المرفوعة وملف app-ads.txt الحي. يجب نجاح اختبارات Fresh Install والترقية الحقيقية من حزمة 1.1.4 السابقة والنسخ الاحتياطي والاسترجاع قبل وصف أي Release بأنه VERIFIED.
- **قبل الرفع على Google Play:** يجب إنشاء AAB موقّع بمفتاح الرفع الدائم المطابق لبصمة Play Console، واجتياز QA على نسخة Release وGoogle Play policies / Families / Data Safety. أي Artifact من PR غير موقع لا يصلح للمتجر.
- **قبل تحديث الداشبورد الحي:** استخدام System Updates لرفع ZIP الموثوق بعد نسخة احتياطية قابلة للتحقق؛ لا تُغيّر الموقع تلقائيًا أو تدّعي نشرًا حيًا قبل فحص صحته.
